Read these files at the beginning of an AI-assisted maintenance session:

1. [`product-overview.md`](product-overview.md) — product purpose, users, behavior, and boundaries.
2. [`tech-stack.md`](tech-stack.md) — service topology, dependencies, contracts, and verification commands.
3. [`current-status.md`](current-status.md) — implemented capabilities, verified evidence, gaps, and next priorities.

## Update triggers

Update this bank in the same commit when a change alters product behavior, API fields/enums, service topology, dependencies, validation commands, a recorded gap, or the priority order. Remove stale statements rather than appending contradictory history.
